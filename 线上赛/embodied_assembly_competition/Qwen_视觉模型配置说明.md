# Qwen 视觉模型配置说明

比赛程序使用 `qwen3.7-plus` 识别两张任务卡：

- 任务卡 1：输出场景语义和物品列表；
- 任务卡 2：提取六条装配顺序，并生成项目书规定的方块/托盘触发码。

两张任务卡都是裁判随机生成的图片，不使用任务书中的示例内容。程序严格先完成任务卡一的识别和文本结果输出，再解析任务卡二，并按本次随机顺序执行六步装配。

VisionMaster 不向 Qwen 直接发送图片：它先将任务卡保存为本地 JPG/PNG，再通过 TCP 将完整绝对路径返回给 Python。Python 读取该文件后自动上传给 Qwen；比赛过程中无需人工选择或转换图片。

模型返回的流式文本会带时间戳显示在比赛窗口，同时保存为审计日志；程序不会只展示最终答案。

## 比赛前配置

启动：

```powershell
python scripts/run_competition.py
```

点击“一键比赛”后，在弹窗临时填入自己的 DashScope API Key。密钥只保留在本次程序内存中，不写入项目文件，也不要发给任何人。

比赛电脑需要联网，且 DashScope 账号需要有 `qwen3.7-plus` 的调用权限和可用余额。
