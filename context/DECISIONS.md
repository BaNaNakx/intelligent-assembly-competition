# 关键决策

## 2026-09-10：双电脑同步架构与公开边界

- 使用公开 GitHub 仓库同步源码、测试和脱敏后的持久上下文。
- 不同步 `.codex` 数据库、锁文件、登录凭据或本机全局设置。
- 将跨任务上下文写入 `AGENTS.md`、`PROJECT_STATE.md`、`DECISIONS.md` 和 `TASK_LOG.md`。
- 历史 Codex 对话、截图、历史压缩包、Office/PDF 资料、第三方安装包和本机运行参数只保存在离线迁移包中。
- 所有公开的新文件在提交前检查 API 密钥、凭据、邮箱、电话、个人姓名和本机用户目录。

## 当前实现约定

- `线下赛/决赛代码` 是当前决赛主版本。
- 工具 DO1 控制吸气，工具 DO0 控制吹气；动作必须互锁，释放吹气结束后关闭 DO0。
- 实机参数不写死为未经确认的值，使用参数配置并在现场验证。
