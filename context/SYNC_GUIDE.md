# 双电脑同步指南

## 第一次在另一台电脑使用

1. 安装 Git。
2. 克隆公开仓库。
3. 在 Codex 中把仓库根目录添加为本地项目。
4. 新任务先让 Codex 使用 `intelligent-assembly-sync` 拉取并读取项目状态。
5. 如需完整比赛资料或原始对话，使用离线迁移包单独复制，不要提交到公开仓库。

## 每次开始工作

1. 确认没有未保存的本地修改。
2. 执行 `git pull --ff-only`。
3. 阅读 `PROJECT_STATE.md`、`DECISIONS.md` 和 `TASK_LOG.md` 最新条目。

## 每次结束工作

1. 运行相关测试。
2. 更新 `PROJECT_STATE.md` 和 `TASK_LOG.md`。
3. 检查差异、API 密钥、凭据和个人信息。
4. 创建聚焦的提交并推送。

两台电脑不要同时直接修改同一文件。需要并行工作时，各自使用独立分支，再审查合并。
