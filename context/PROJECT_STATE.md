# 项目当前状态

更新时间：2026-09-11

## 云同步

- 公开仓库：`https://github.com/BaNaNakx/intelligent-assembly-competition`
- 默认分支：`main`
- 本地分支已跟踪 `origin/main`，两台电脑通过 fast-forward 拉取和普通推送同步。

## 当前主版本

- 主要维护目录：`线下赛/决赛代码`
- Python 要求：3.11 及以上
- 包名：`embodied-assembly-competition`
- 核心模块覆盖 AUBO/ARCS JSON-RPC、机械臂运动、VisionMaster TCP、千问视觉解析、ARM 语音、比赛运行时、GUI、参数管理和日志审计。

## 最近完成

- 按决赛文档扩展为 9 种物块颜色。
- 任务二支持固定 7 步，前 6 步放托盘，第 7 步方块叠放，并复用前序记录的放置位姿。
- GUI 已加入决赛参数和运行状态展示。
- 吸盘改为双 DO 互锁：工具 DO1 吸气，工具 DO0 短时吹气释放；默认高电平有效，吸取与释放等待时间均为 0.20 秒。
- 云同步副本已重新运行 141 项单元测试并全部通过。
